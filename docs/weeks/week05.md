# 5주차 — Tensor Core와 MMA

[전체 로드맵](../../README.md#주차별-로드맵) · [← 4주차](week04.md) · [6주차 →](week06.md)

**구현 목표:** 사용하는 GPU에 맞는 MMA atom과 `TiledMma`를 이해하고 저정밀도 GEMM을 수정합니다.

## 구현 과제

1. 지원되는 FP16 또는 BF16 입력 예제를 선택합니다. 기본 실험은 FP32 누산으로 구성하고 출력 dtype도 별도로 명시합니다.
2. MMA atom의 연산 shape, warp 또는 협력 스레드 그룹, 스레드별 입력·누산 fragment의 역할을 정리합니다.
3. 유효한 tile 구성 두 가지 이상을 비교합니다. layout·alignment 제약 때문에 실행할 수 없는 구성도 이유와 함께 기록합니다.
4. 저정밀도로 변환된 동일 입력을 기준 구현에도 사용해 검증하고, 같은 정밀도 조건의 cuBLAS와 비교합니다.

FP16과 BF16 두 입력 dtype 모두의 구현은 선택 과제입니다.

## 산출물 및 완료 기준

- [ ] GPU가 지원하는 FP16 또는 BF16 GEMM 예제를 수정했다.
- [ ] 입력·누산·출력 dtype과 MMA atom 및 fragment의 역할을 정리했다.
- [ ] 최소 두 가지 유효한 tile 구성의 오차·실행 시간·TFLOPS를 기록했다.
- [ ] 지원하지 않는 layout·alignment 구성이 있다면 이유를 기록했다.
- [ ] 동일한 저정밀도 입력과 정밀도 조건으로 기준 구현 및 cuBLAS와 비교했다.
- [ ] FP32 baseline과의 성능·오차 차이를 연산 정밀도와 함께 설명했다.
- [ ] 소스 코드, 빌드·실행 명령, 검증 로그와 해당 주차의 결과·해석을 남겼다.

검증과 측정은 [공통 규칙](../../README.md#공통-검증-및-측정-규칙)을 따릅니다. 완료한 항목은 `- [ ]`를 `- [x]`로 바꿉니다.
