# 1주차 — CUDA GEMM 기초

[전체 로드맵](../../README.md#주차별-로드맵) · [2주차 →](week02.md)

**구현 목표:** `A[M,K] × B[K,N] = C[M,N]`을 FP32, row-major 기준으로 직접 계산합니다.

## 구현 과제

1. 스레드 하나가 출력 원소 하나를 계산하는 naive GEMM을 작성합니다.
2. A와 B의 tile을 shared memory에 적재하고 재사용하는 tiled GEMM을 작성합니다. 우선 `16×16` tile에서 시작합니다.
3. 범위를 벗어난 입력은 0으로 채우고, 유효한 출력만 저장합니다. 경계 밖 스레드도 필요한 block barrier에 참여하도록 구성합니다.
4. 작은 행렬은 CPU 기준값과 비교하고, tile 배수가 아닌 크기에서도 검증합니다.

## 산출물 및 완료 기준

- [ ] FP32 naive GEMM과 shared-memory tiled GEMM 소스를 작성했다.
- [ ] 작은 입력의 CPU 기준값 비교와 tile 배수가 아닌 입력의 정확성 검사를 통과했다.
- [ ] 두 커널의 실행 시간 표를 남겼다.
- [ ] 스레드→출력 좌표 그림을 작성했다.
- [ ] 알고리즘 수준의 global memory load 횟수를 비교하고, 실제 DRAM 트래픽에 미치는 캐시 영향을 구분해 설명했다.
- [ ] 소스 코드, 빌드·실행 명령, 검증 로그와 해당 주차의 결과·해석을 남겼다.
