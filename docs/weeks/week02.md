# 2주차 — CUTLASS 실행과 기준 성능

[전체 로드맵](../../README.md#주차별-로드맵) · [← 1주차](week01.md) · [3주차 →](week03.md)

**구현 목표:** 공식 GEMM 예제를 수정해 반복 가능한 벤치마크를 만듭니다.

## 구현 과제

1. 고정한 CUTLASS 버전에서 GPU에 맞는 기본 GEMM 예제를 빌드합니다. 원본 경로와 수정 사항을 기록합니다.
2. `M/N/K`, 반복 횟수, seed를 실행 인자로 받고, layout·dtype·leading dimension을 명시합니다.
3. 같은 입력으로 CUTLASS와 cuBLAS를 실행합니다. 우선 `alpha=1`, `beta=0`으로 통일합니다.
4. cuBLAS의 column-major 규약과 row-major 입력 사이의 대응을 작은 비대칭 행렬로 검증합니다. TF32 허용 여부 등 compute/math mode도 기록합니다.

## 산출물 및 완료 기준

- [ ] 수정한 공식 GEMM 예제와 원본 경로·수정 사항을 남겼다.
- [ ] 정방형·직사각형·작은 행렬의 결과 CSV에 정확성, 실행 시간, TFLOPS를 기록했다.
- [ ] CUTLASS와 cuBLAS의 연산·정밀도 조건이 일치하는지 확인했다.
- [ ] 비대칭 행렬로 cuBLAS의 layout 대응을 검증했다.
- [ ] 빌드 및 벤치마크 재실행 명령을 남겼다.
- [ ] 소스 코드, 빌드·실행 명령, 검증 로그와 해당 주차의 결과·해석을 남겼다.

검증과 측정은 [공통 규칙](../../README.md#공통-검증-및-측정-규칙)을 따릅니다. 완료한 항목은 `- [ ]`를 `- [x]`로 바꿉니다.
